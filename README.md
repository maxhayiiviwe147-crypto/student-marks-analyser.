# Student Marks Analyser

A Python application for analysing student academic performance.

## About the Project

Student Marks Analyser is a beginner-friendly Python project that helps students understand their academic performance by calculating averages, identifying their highest and lowest marks, and highlighting subjects that need improvement.

## Subjects Analysed

- Computer Literacy
- Statistics
- Linear Algebra
- Calculus
- Database Management

## Features

- Accepts marks for five subjects.
- Validates marks to ensure they are between 0 and 100.
- Calculates the average mark.
- Identifies the highest and lowest marks.
- Classifies overall performance.
- Identifies subjects with marks below 50%.
- Handles invalid numerical input.

## Technologies Used

- Python
- Functions
- Lists and dictionaries
- Loops and conditional statements
- Exception handling

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   `python main.py`

5. Enter your marks when prompted.
